Trust local HTTPS

LaraMonster signs a certificate for every site with its own certificate authority, created on this computer and never shared. Trusting it once gives every https:// site a valid padlock, so secure cookies, OAuth callbacks, service workers and webhooks behave like they do in production.

This step is required. Your system asks for your password once, and browsers on Linux need certutil to learn about the certificate.
